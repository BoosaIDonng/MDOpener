怎么用？三步开始

装好后无需任何设置，它就像系统自带的阅读器一样工作。

1

从 GitHub Releases 下载 APK 安装（约 3MB）。签名固定，升级可直接覆盖安装。

2

点开任意 .md 文件

在文件管理器里点击 .md 文件，选「用 MD Opener 打开」并设为默认。微信/QQ 文件先转存到手机。

3

呼出目录跳转章节，页内搜索关键词，需要打印或分享时一键导出 PDF。

常见问题

关于在手机上查看 Markdown 文件，最常被问到的问题。

手机怎么打开 .md 文件？

安卓系统本身不识别 .md 文件。安装 MD Opener 后，在任意文件管理器里直接点击 .md / .markdown / .mdown 文件，选择用 MD Opener 打开，即可看到排版好的正文，无需导入或转换。

微信、QQ 里收到的 Markdown 文件怎么看？

先把文件转存到手机存储（或用文件管理器进入微信/QQ 的下载目录），点击后选择 MD Opener 打开即可。纯文本内容也可以直接用系统「分享」发给 MD Opener 渲染。

MD Opener 收费吗？有广告吗？

完全免费，MIT 协议开源。应用没有广告，也没有申请联网权限，所有渲染都在手机本地完成。

支持把 Markdown 导出成 PDF 吗？

支持。可选 A4/A5/B5/Letter/Legal 纸张，导出的 PDF 文字为矢量可选中，可保留整页背景色，还支持用 --- 分割线强制分页。

中文 Markdown 文件打开是乱码怎么办？

MD Opener 内置编码检测：自动识别 UTF-8 与 GBK/GB2312（GB18030）编码的文件，老文档也能正常显示，无需手动转码。

最低支持什么安卓版本？

Android 7.0（API 24）及以上，覆盖绝大多数在用设备。
